# CDK Patterns & Practices

## Stack Structure

- **Stateful stack**: DynamoDB tables, SQS queues, DLQ monitoring — resources with persistent state
- **Stateless stack**: Lambdas, Step Functions, ECS Fargate tasks, EventBridge rules/targets — resources that can be replaced without data loss
- Both stacks extend `GitStack` from `@orcabus/platform-cdk-constructs/deployment-stack-pipeline`

## CDK Nag Compliance

- All stacks must pass `AwsSolutionsChecks` with zero errors and zero warnings
- Use `NagSuppressions` to suppress expected findings with a documented reason
- Stack-level suppressions go in the stack constructor
- Tests in `test/stage.test.ts` synthesize stacks and validate nag compliance

## Resource Patterns

- Import existing resources by name/ARN (e.g., `TableV2.fromTableName`, `EventBus.fromEventBusName`, `Secret.fromSecretNameV2`)
- Props interfaces define all external resource references needed by a stack
- Per-stage configuration is generated by factory functions in `config.ts`

## Lambda Conventions

- Python Lambdas use `@aws-cdk/aws-lambda-python-alpha` for bundling
- Lambda code lives in `app/lambdas/<name>_py/`
- Entry file matches directory name (e.g., `check_job_status_py/check_job_status.py`)

## Step Functions

- ASL templates live in `app/step-function-templates/`
- Step Functions use task tokens for async wait patterns
- Built via helper functions in `infrastructure/stage/step-functions/`

## ECS Fargate Tasks

- Docker images in `app/ecs/<task_name>/`
- Each task has a Dockerfile, docker-entrypoint.sh, and scripts/ directory
- Tasks receive secrets (ICAv2 access token, OrcaBus token) and SSM parameters

## EventBridge

- External events arrive on `OrcaBusMain` event bus
- Event source and detail type are configurable per stage
- Rules, targets, and pipes are built by dedicated modules under `infrastructure/stage/`

## Security

- Secrets accessed via Secrets Manager (never hardcoded)
- SSM Parameters for non-secret configuration (e.g., hostnames)
- IAM policies follow least privilege; suppressions require documented reasons
